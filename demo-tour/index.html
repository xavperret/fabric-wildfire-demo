Deep Dive

⚙️ How It Works Under the Hood

🛰️ 1. Satellite Ingestion NASA FIRMS API → Fabric Eventstream every 10 min. Each detection = lat, lon, FRP (fire radiative power), confidence, satellite name.
📡 2. KQL Processing Eventhouse clusters detections by proximity (geo_distance_2points), joins communes, computes priority_score = FRP × log(population).
🔔 3. Activator Rule When frp > 50, Fabric triggers a Teams adaptive card with zone, score, and recommendation.
🤖 4. AI Skill Agent_Wildfire uses DispatchResults as its data source. Natural language → KQL → structured answer with sources cited.
Narrator: "The whole pipeline is event-driven. No polling, no batch jobs. Data flows from satellite to dispatch recommendation in under 60 seconds."
